  3. 在hugo生成的页面嵌入pdf在线浏览的一种方式(shortcode 方案)😸

完整的 shortcode 方案，分三步：

第一步：创建 shortcode 文件

在 Hugo 项目根目录新建 layouts/shortcodes/pdf.html：

<object data="{{ .Get 0 }}" type="application/pdf" width="100%" height="{{ with .Get 1 }}{{ . }}{{ else }}800px{{ end }}">
  <iframe src="{{ .Get 0 }}" width="100%" height="{{ with .Get 1 }}{{ . }}{{ else }}800px{{ end }}" style="border: none;">
    <p>你的浏览器不支持内嵌 PDF，请 <a href="{{ .Get 0 }}">下载查看</a>。</p>
  </iframe>
</object>

这里用了 <object> 包 <iframe> 的结构：object 是标准做法，iframe 作为兜底，最内层的 <p> 是最后的 fallback。

第二步：放 PDF 文件

mkdir -p static/files
cp your-paper.pdf static/files/

构建后路径为 /files/your-paper.pdf。

第三步：页面里调用

带高度参数（第二个参数，支持 px 和 vh）：

参数说明

参数 必填 说明
第一个 是 PDF 的 URL，可以是站内路径 /files/x.pdf 或外链 https://...
第二个 否 高度，默认 800px

可选增强：移动端适配

如果担心小屏幕高度不够，可以改 shortcode 用 {{ .Get 1 }} 的同时加个 CSS 类：

<object class="pdf-embed" data="{{ .Get 0 }}" type="application/pdf" width="100%" height="{{ with .Get 1 }}{{ . }}{{ else }}800px{{ end }}">
  ...
</object>

在 assets/css/ 或主题自定义样式里加：

.pdf-embed {
  border: 1px solid #ddd;
  border-radius: 4px;
}
@media (max-width: 768px) {
  .pdf-embed {
    height: 60vh !important;
  }
}

改完 hugo server 本地起一下，访问对应页面确认能渲染即可。

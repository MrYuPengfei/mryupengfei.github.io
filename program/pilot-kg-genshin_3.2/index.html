原神桌面伙伴v3.2· 项目详细介绍

仓库：https://github.com/MrYuPengfei/Pilot-KG-Genshin 当前版本：v3.2｜许可协议：Apache License 2.0｜平台：Windows（可跨平台移植）

本文全部配图均来自本目录下的 data/，采用相对路径引用，随仓库一同分发。

一、项目定位

原神桌面伙伴（Pilot-KG-Genshin）是一个基于 PySide6 + pygame-ce 的桌面陪伴工具。 它把《原神》的角色逐帧动画搬到了系统托盘里：可切换 28 位人物、拖动窗口、 按时段自动问候、播放角色语音与地区背景音乐，并内置一个可交互的原神知识图谱浏览器。

本项目是通用 Pilot-KG 系列的前置项目。在持续迭代中，它将演进为跨平台、 可自定义主题与素材、具备知识获取与匿名聊天能力的桌面小助手。

维度 说明
名称由来 Pilot（飞行员）＋KG（Knowledge Graph，知识图谱）＋Genshin
主类 Pilot（pilot.py）
内置人物 28 位，帧数 9476、语音 341 条
背景音乐 蒙德 / 璃月 / 稻妻 三个地区
知识图谱 12 类实体、1911 个节点、7511 条关系
安装包 约 480MB，每用户目录安装，免管理员权限

二、界面与功能一览

2.1 托盘菜单：程序的唯一入口

程序启动后常驻系统托盘，没有主窗口，所有操作都从托盘图标右键菜单进入。

菜单结构极简，共五项：

菜单项 说明
人物 28 位角色子菜单，由资源库动态生成，导入的新人物即时出现
音乐 地区背景音乐 + 人物语音开关，选中项以「～」标记
管理面板 打开图形化管理面板（见 2.3）
显示 唤回被隐藏的伙伴窗口
退出 保存配置并退出

右键桌面上的伙伴窗口可直接隐藏它；隐藏后随时可从托盘「显示」唤回。

2.3 管理面板

托盘「管理面板」打开，五个标签页，所有改动即时生效并自动保存。

人物管理

左侧列出全部人物（可滚动），选中后显示首帧预览、帧数、语音数与当前状态； 下方可按人物调整帧间隔（201000ms）与缩放比例（0.13.0），并一键设为当前伙伴或删除。

音乐管理

地区背景音乐播放/停止、人物语音开关、一键静音，与托盘音乐菜单的「～」状态双向同步。

素材管理

显示资源统计（存储后端、人物/地区/帧/语音数量、数据库大小）， 并提供 zip 素材包与素材目录两种导入方式。

帮助文档

内置导入注意事项、版本变更记录、第三方开源库许可与项目地址，离线可查。

截图为 v3.1 界面（拍摄于本轮文档完善之前），当前 v3.2 的帮助页已扩展为五章， 新增「管理面板使用说明」，开源地址亦已更新为 Pilot-KG-Genshin。

2.4 知识图谱可视化

管理面板的第四个标签页，把 GenshinKG/data 下的 27 个 CSV 关系数据变成可交互的图谱。

实体检索与自我中心网：输入实体名（支持全名补全）后，画布以该实体为中心做放射状布局， 12 类实体用不同颜色区分，边上标注关系名。

属性与关系详情：右侧同步显示选中节点的全部属性字段与关系清单（图中为可莉的 42 条关系）。

双击展开：双击任一节点即以其为中心重新展开，可逐层探索整个图谱。

交互方式：单击看详情、双击展开、滚轮缩放、拖拽平移。 图谱数据采用懒加载——首次切到该页才读取，不拖慢面板启动。

三、技术实现

3.1 架构

Pilot (pilot.py)
├── resource_store.py    资源访问抽象层：优先读 assets.db，回退文件系统
├── asset_importer.py    素材包导入核心（目录 / zip → 数据库 upsert）
├── manager_panel.py     五个标签页的图形化管理
│   └── kg_store.py      图谱数据层：名称索引 + 邻接表
│   └── kg_view.py       图谱可视化：QGraphicsView 自我中心网画布
└── config.yaml          帧率、缩放、当前人物、音频开关（即时写盘）

3.2 SQLite 资源库

项目原有 9476 个 PNG 帧与 341 个 MP3，合计近万个零散文件。v2.0 起全部收进 单个 assets.db（约 460MB），表结构极简：

CREATE TABLE assets (
    role     TEXT NOT NULL,   -- 角色名，或地区名（蒙德/璃月/稻妻）
    kind     TEXT NOT NULL,   -- frame / voice / bgm
    name     TEXT NOT NULL,   -- 原始文件名
    category TEXT,            -- 语音分类：greeting/chat/know
    data     BLOB NOT NULL,
    PRIMARY KEY (role, kind, name)
);

收益：分发、备份、杀毒扫描都从"近万文件"变成"单文件"；ResourceStore 保证没有数据库时仍能回退读目录，两种形态都能跑。

3.3 帧缓存

数据库解决了"读取"，但解码与缩放才是真正的性能大头。 现在的做法是：切换人物时一次性预加载并预缩放该人物全部帧（含 mask 缓存）， 之后 act() 只做内存切换——实测 219 帧的加载成本约 0.5 秒，一次性付清， 动画期间磁盘 I/O 与重复解码降为 0。Ctrl +↑/↓ 缩放后自动重建缓存。

3.4 第三方素材导入

用户可导入自定义人物与地区，目录布局沿用项目约定：

素材包/
  png/<人物>/*.png                # 人物帧
  music/<人物>/*.mp3              # 语音，按 早上好/闲聊*/想要了解* 命名自动分类
  music/<地区>/background.mp3     # 地区背景音乐（目录含 background.mp3 即识别为地区）

导入是 upsert（同名覆盖，不产生重复），新人物自动在 config.yaml 登记默认 帧率与缩放，导入后菜单即时刷新，无需重启。

3.5 打包链路

pilot.py → PyInstaller（onedir）→ Inno Setup 6 → 安装向导。

需要注意一个构建陷阱：PyInstaller 的 --clean 清缓存步骤可能被安全策略拦截而静默跳过， 导致复用旧 Analysis 缓存——新模块不进包，但构建看上去是成功的。 因此打包前须手动清理 build/ 与 %LOCALAPPDATA%\pyinstaller， 打包后逐项校验 PYZ-00.toc 模块清单与 _internal 数据是否就位。

七、快速上手

源码运行

git clone https://github.com/MrYuPengfei/Pilot-KG-Genshin.git
cd Pilot-KG-Genshin
uv sync
uv run python pilot.py

可选：把 png/、music/ 的零散资源打包为数据库（有数据库时程序自动使用，否则回退读目录）：

uv run python tools/build_assets_db.py

安装包运行

下载 inno_build/原神桌面伙伴安装向导.exe 双击运行即可，无需 Python 环境。

开发与测试

uv run pytest                                                   # 19 项测试
QT_QPA_PLATFORM=offscreen SDL_AUDIODRIVER=dummy uv run python pilot.py   # 离屏冒烟

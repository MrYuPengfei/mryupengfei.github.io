10分钟掌握 JSON 格式

目标：快速理解 JSON 是什么、怎么写、怎么用，看完即可上手读写 JSON。

一、JSON 是什么？（1分钟）

JSON（JavaScript Object Notation）是一种轻量级数据交换格式：

  • 纯文本、易读易写，人和机器都友好
  • 独立于语言：几乎所有编程语言都支持
  • 应用场景：API 数据传输、配置文件、数据存储（如 Nextcloud、Docker 的配置）
{
  "name": "WorkBuddy",
  "version": "1.0"
}

二、六种数据类型（2分钟）

类型 示例 说明
字符串 string "hello" 必须用双引号
数字 number 42、3.14、-7 不分整数/浮点
布尔 boolean true、false 全小写，无引号
空值 null null 全小写
对象 object {"key": "value"} 键值对集合，键必须是字符串
数组 array [1, 2, 3] 有序列表

三、核心语法规则（3分钟）

{
  "user": "张三",
  "age": 28,
  "isAdmin": false,
  "hobbies": ["读书", "编程", "NAS折腾"],
  "address": {
    "city": "深圳",
    "zip": "518000"
  },
  "spouse": null
}

必须遵守的规则：

  1. 键名必须加双引号："name" ✅，name ❌，'name' ❌（单引号非法）
  2. 数据之间用逗号分隔，但最后一项后面不能有逗号（尾随逗号非法）
  3. 顶层只能是对象或数组
  4. 大小写敏感：true ✅，True ❌
  5. 不支持注释（JSON5/JSONC 除外）
  6. 字符串中特殊字符需转义：\"、\\、\n、\t

常见错误对照：

// ❌ 错误：尾随逗号
{"a": 1, "b": 2,}

// ❌ 错误：单引号
{'a': 1}

// ❌ 错误：键没加引号
{a: 1}

// ✅ 正确
{"a": 1, "b": 2}

四、嵌套结构：对象套数组（2分钟）

实际 API 返回的数据通常是多层嵌套：

{
  "code": 200,
  "data": {
    "users": [
      {"id": 1, "name": "Alice", "tags": ["admin", "dev"]},
      {"id": 2, "name": "Bob", "tags": ["user"]}
    ],
    "total": 2
  }
}

读取路径思维：data.users[0].name → "Alice"

五、各语言中的使用（1分钟）

Python：

import json
data = json.loads('{"a": 1}')      # 字符串 → 字典
text = json.dumps(data, ensure_ascii=False, indent=2)  # 字典 → 字符串

JavaScript：

const obj = JSON.parse('{"a": 1}');
const str = JSON.stringify(obj, null, 2);

常用工具：jq（命令行处理）、VS Code 格式化（Shift+Alt+F）、在线校验 jsonlint.com

六、速查备忘（1分钟）

  • 双引号、无尾逗号、无注释 —— 三大铁律
  • 配置文件变体：JSONC（允许注释，VS Code 用）、JSON5（更宽松）、JSONL（每行一条 JSON，适合日志/大数据）
  • 调试报错先看：逗号、引号、括号是否配对

一分钟自测

  1. 下面哪个是合法 JSON？
    • A. {name: "Tom"}
    • B. {"name": 'Tom'}
    • C. {"name": "Tom"} ✅
  2. JSON 中注释怎么写？—— 标准 JSON 不支持注释
  3. ["a", "b",] 合法吗？—— 不合法，尾随逗号

恭喜你，已经掌握 JSON 的核心要点！剩下的就是在实际项目中多写多练。
